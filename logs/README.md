# Model evidence

The main experiment log contains 66 injection calls (60 paired T1–T10 and six extra before-only T11/T12), ten format tests, and three factual probes. Each call preserves its input report, prompt, raw response, model, timestamp, latency and returned usage. The separate smoke and pilot files are excluded from main trial totals. Semantic judgments are in the results folder. `llm_log.jsonl` is reserved for seeded closed-loop simulation calls; no completed five-seed simulation dataset is claimed.
